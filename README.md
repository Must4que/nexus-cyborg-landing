# NEXUS — Beyond Human

A responsive, futuristic cyborg-themed landing page built with **HTML, CSS, and vanilla JavaScript**. No frameworks or build tools required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local dev server, you can use VS Code's Live Server extension or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Responsive desktop, tablet, and mobile layouts
- Custom CSS cyborg illustration (no image assets needed)
- Dark sci-fi aesthetic with cyan/violet accents and HUD-style details
- Mobile navigation menu
- Scroll reveal animations and animated metrics
- Cursor glow effect on pointer devices
- Email form UI with demo-only feedback (no data is sent or stored)
- Reduced-motion accessibility support

## Customize

- Edit content in `index.html`.
- Change colors and layout in `style.css` using the CSS variables in `:root`.
- Adjust interactions in `script.js`.

## GitHub Pages

Push these files to a GitHub repository, then open **Settings → Pages** and select your deployment branch (usually `main`) and root folder (`/`). Save to publish.

> The email form is a front-end demo. Connect a backend or form service before collecting real signups.
